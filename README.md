|:---------|:---|

## 项目简介

本项目是一个面向校园招聘场景的**数据采集 + 清洗分析 + 可视化展示**一体化平台。系统以就业信息网公开的招聘信息为数据源，将原始 CSV 数据清洗入库，通过后端接口实时聚合统计，并在 Web 端以图表大屏的形式展示岗位分布、薪资水平、行业结构等分析结果，帮助使用者快速把握当前招聘市场的整体状况。

**数据规模：**

| 指标 | 数量 |
|:---|:---|
| 招聘岗位总数 | 31,035 条 |
| 覆盖城市 | 247 个 |
| 含薪资岗位 | 28,979 条 |

## 技术架构

项目采用前后端分离架构，前端负责界面与图表渲染，后端负责数据清洗、存储与统计聚合。

| 层次 | 技术选型 |
|:---|:---|
| 前端框架 | Vue 3（组合式 API） |
| 路由与请求 | Vue Router 4、Axios |
| 可视化 | Apache ECharts 5 |
| 构建工具 | Vite 5 |
| 后端框架 | Flask 3 + Flask-SQLAlchemy |
| 数据库 | SQLite（可通过 `DATABASE_URL` 切换 MySQL 等） |
| 数据处理 | pandas、numpy |
| 登录认证 | Flask Session + Werkzeug 密码哈希 |

**目录结构：**

```
10.11/
```

## 核心功能

### 1. 数据采集与清洗
- 从就业信息网抓取招聘数据并保存为 CSV 文件；
- 解析薪资字符串（如 `5-8千/月` → 最低 5000、最高 8000、平均 6500 元）；
- 按平均薪资划分 7 档薪资区间，清洗城市、公司类型、公司规模、行业等字段；
- 通过 `scripts/import_data.py` 批量写入数据库，单次导入 3 万余条记录。

### 2. 统计分析
后端通过 SQL 聚合实时计算，不依赖预生成的静态结果，共提供 10 个分析维度：

1. 招聘岗位城市分布 Top15
2. 行业分布 Top15
3. 薪资区间分布
4. 各城市平均薪资 Top15
5. 公司规模分布
6. 公司类型分布
7. 岗位关键词热度（数据、算法、运营等 20 个词）
8. 岗位名称词频 Top20
9. 热门城市 × 薪资区间交叉分布
10. 各城市高薪岗位（≥2 万元）比例 Top10

### 3. 可视化展示
- 顶部 4 张概览卡片：岗位总数、覆盖城市数、含薪资岗位数、涉及行业数；
- 10 个 ECharts 图表，涵盖柱状图、饼图、环形图、堆叠柱状图，支持 tooltip 与图片导出；
- 图表下方给出分维度的数据分析结论。

### 4. 岗位明细查询
- 支持按岗位/公司关键词、城市、行业、薪资区间、公司规模、公司类型多条件筛选；
- 支持按平均薪资升降序排序、分页浏览（10/20/50 条每页）；
- 点击任意行弹出详情弹窗，展示岗位描述、公司信息等完整内容。

### 5. 用户登录
- 基于 Flask Session 的登录认证，密码使用 Werkzeug 哈希存储，会话有效期 7 天；
- 统计接口与岗位接口均需登录后访问，未登录返回 401；
- 前端通过路由守卫拦截未登录访问，登录后自动回到原页面，顶栏显示当前用户并支持退出登录；
- 首次启动自动创建默认账号：`admin` / `admin123`。

## 主要接口

| 接口 | 说明 |
|:---|:---|
| `POST /api/auth/login` | 登录 |
| `POST /api/auth/logout` | 退出登录 |
| `GET /api/auth/me` | 获取当前登录用户 |
| `GET /api/stats/dashboard` | 仪表盘全部统计数据 |
| `GET /api/stats/<维度>` | 单项统计（如 `city-count`、`salary-range`） |
| `GET /api/jobs` | 岗位分页列表（支持多条件筛选与排序） |
| `GET /api/jobs/filters` | 筛选下拉项 |
| `GET /api/jobs/<id>` | 岗位详情 |
| `GET /api/health` | 健康检查 |

## 运行方式

**后端：**

```bash
cd 10.11/backend
pip install -r requirements.txt
python scripts/import_data.py   # 首次运行：导入 CSV 数据
python app.py                   # 启动服务，默认 http://localhost:5000
```

**前端：**

```bash
cd 10.11/frontend
npm install
npm run dev                     # 启动开发服务器，默认 http://localhost:5173
```

浏览器打开 `http://localhost:5173`，使用默认账号 `admin / admin123` 登录即可查看数据。
